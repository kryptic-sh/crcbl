Controls

← and → move the paddle, Space launches the ball and restarts after a win or a loss. Click the canvas first: a canvas has to have keyboard focus to receive keys, and browsers will not start audio until you interact with the page.

What is actually running

The same apps/breakout that builds a native binary, with four differences the browser forces and nothing else: start-up is polled across several frames because requestDevice is a promise; the frame loop is driven by requestAnimationFrame out here rather than by a loop inside the engine; the clock is the browser's, because wasm32-unknown-unknown has no Instant; and the high score lives in the Origin Private File System instead of ~/.config.

Open the console for the engine's log — the wasm module imports nothing, not even console.log, so log lines are queued inside wasm and drained by the page each frame. crcbl.audio(), crcbl.saves() and crcbl.logLevel(4) are there too.
