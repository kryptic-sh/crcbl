crcbl-webgpu seam probe

A page with no engine running. It loads a demo's wasm module without booting it, so nothing has claimed the single GPU command channel, and then it pumps that channel itself — drain, replay, deliver, once per requestAnimationFrame frame. That is the whole page: the commands come from crcbl-webgpu's probe exports, which web/tools/probe-e2e.mjs drives from outside over the DevTools protocol.

There is nothing to look at. The canvas below is here because it is a subject: a surface has to resolve to a real element and answer a real GPUCanvasContext, and that is the element it resolves to.
