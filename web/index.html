Crucible

A game engine written from scratch, in Rust.

Crucible owns its stack: its own Vulkan backend, its own Wayland and X11 windowing, its own ECS, renderer, physics, netcode and audio, with hand-written bindings rather than frameworks. There is a second graphics backend on wgpu, and that is what makes this page possible — the same engine, the same sample code, compiled to wasm32-unknown-unknown and drawing through WebGPU.

Every sample that can run in a browser is published here from the moment it exists, so the browser target cannot quietly rot: a broken wasm build is a broken CI, and a broken CI blocks the merge.

Demos

  • Breakout

    The first playable sample. Client and server over an in-memory transport, orthographic camera, engine-rendered HUD, spatial audio on every bounce, and a high score kept in the Origin Private File System.

Running them

These need WebGPU: Chrome or Edge 113 and later, Safari 18 and later, or Firefox with WebGPU enabled. The demos are single-threaded — GitHub Pages cannot send the COOP/COEP headers SharedArrayBuffer requires, so this deployment is built without it rather than pretending otherwise.
